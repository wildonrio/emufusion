# Phase 1A Android core QA

This directory contains a standalone libretro frontend used to test EmuFusion's
Phase 1A Android ARM64 core candidates without a handheld. It is qualification
evidence, not a second runtime frontend and not evidence that a core is ready
to ship.

## What a PASS means

For 180 emulated frames on an `arm64-v8a` Android emulator, the exact `.so`
artifact must:

1. load redistributable test content;
2. invoke video, audio, input-poll, and input-state callbacks, with non-black
   pixels in at least 90% of delivered video frames; selected late Phase 1
   cores additionally replay the same 30-frame interval with and without a
   held joypad button and require the serialized end states to differ;
3. expose a nonzero serialization size and survive **100 consecutive**
   serialize/unserialize cycles with byte-identical state, allowing one
   documented first-cycle canonicalization pass for descriptive save-container
   metadata; and
4. allow a write/read/restore check when the fixture exposes save RAM.

The JSON retains `sramSize: 0` when a legal fixture has no cartridge save RAM;
that is not presented as a successful SRAM test. A core that only renders a
firmware-error screen is **BLOCKED**, even if some generic callbacks fire.
Every runnable system uses the same 100-cycle gate; there is no weaker
single-cycle path. A core's first cycle may canonicalize descriptive metadata,
but every following cycle must remain byte-stable.

## Run

Start an Android ARM64 emulator, then build and test the runnable candidates:

```sh
python3 engines/qa/run_phase1a_qa.py --serial emulator-5554 --build-runnable
```

`--build-runnable` rebuilds the available Phase 1A cores before testing. The
runner requires NDK `27.0.12077973`, refuses any serial not named `emulator-*`,
verifies `ro.kernel.qemu=1`, and never contacts a physical device. Results and
full core logs are written to ignored paths under
`engines/build/qa-results/`.

The runnable Neo Geo case also builds the pinned open ngdevkit fixture. On
macOS its upstream prerequisites are available from the official tap with
`brew tap dciabrin/ngdevkit`, `brew trust dciabrin/ngdevkit`, and
`brew install ngdevkit make imagemagick`. The fixture builder verifies the
ngdevkit source, examples source, nullbios, generated cartridge, and MAME hash
file by SHA-256; it will not accept a substituted BIOS.

## EmuFusion activity qualification

To build a qualification-only APK and exercise every legally runnable fixture
through `InternalGameLaunchActivity` and `LucentGameActivity` on the emulator:

```sh
python3 unified-android/tools/run_phase1a_activity_qa.py --serial emulator-5554
```

This separate harness preserves the production `TextureView`, verifies a
visible nonempty core frame, pause/resume, Exit to EmuFusion, and a committed then
restored Quick Resume. It records screenshots and JSON under
`unified-android/build/phase1a-activity-qa/`. The exported launcher bridge and
all core libraries exist only in the explicitly opted-in qualification APK;
the default/release build remains core-free and deny-by-default.

## Limits

This probe does not validate sustained performance, rendering correctness,
touch/dual-screen behavior, long-session save compatibility, or physical
controller mappings. Those remain device/UI qualification gates. Proprietary
proprietary firmware is never downloaded by this harness. The ColecoVision
candidate remains audit-only because its source-to-binary relationship was not
reproduced; the formal runner records it as BLOCKED and does not stage it.
SwanStation's source archive
contains PCSX-Redux OpenBIOS under its MIT license; no proprietary Sony BIOS is
used.

FreeIntv remains blocked even though the primary jzIntv archive contains
binary-only `miniexec.bin` and `minigrom.bin` substitutes: corresponding source
and file-scoped license evidence are absent, and they are intentionally
incompatible with many cartridges. EmuFusion does not bundle or accept them.

Neo Geo AES/MVS no longer needs a proprietary QA exception: the pinned open
ngdevkit nullbios and homebrew cartridge pass the full gate. Neo Geo CD/CDZ
remains explicitly blocked because no compatible, explicitly licensed open
replacement for its required main CD BIOS was found. Open `000-lo.lo` and open
disc content alone are insufficient. Proprietary inputs are never downloaded
or bundled; the detailed primary-source audit is in
[`../firmware/README.md`](../firmware/README.md).
