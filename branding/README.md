# EmuFusion identity

`lucent-icon-master.png` is the 1024 × 1024 source artwork for the EmuFusion app
icon. The mark represents a single beam entering a precision optical aperture
and emerging as a controlled spectrum: a visual shorthand for one library
turning many systems into a coherent experience.

The icon is a EmuFusion original and is distributed with the complete application
under GPLv3. The copy embedded in the independently distributed theme is also
available under the theme's MIT License.
